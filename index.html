SECOND-YEAR PROJECT

Silent Scraper Academy

Vulnerable Web Application & Security Learning Platform

Category

Web Application Security

Platform Stack

PHP (XAMPP), Node.js, Python (FastAPI), HTML/CSS/JavaScript

Testing Tools

Burp Suite, Nmap, Gobuster, FFUF

Overview

Silent Scraper Academy is a full-stack cybersecurity training platform built around a vulnerable web application lab, giving users a safe, isolated environment to practice exploiting real-world web vulnerabilities.

Objective

Design and implement a controlled vulnerable web application (PHP apps hosted via XAMPP) inside a larger training platform, connecting offensive-security methodology with practical, hands-on application security testing.

Attack Surface

Testing was scoped to the vulnerable application's exposed endpoints, authentication and authorization flows, file handling features, and general HTTP behavior — all within the controlled lab environment.

  • Web Reconnaissance & Subdomain Enumeration
  • Authentication Testing
  • Authorization Testing
  • IDOR & Broken Access Control
  • File Upload Vulnerabilities
  • Path Traversal
  • Input Validation
  • HTTP Security Analysis

Methodology

Reconnaissance → Enumeration → Vulnerability Discovery → Validation → Exploitation → Documentation

Technical Implementation

The vulnerable lab environment runs on PHP served via XAMPP. The wider training platform is built with Node.js and Python (FastAPI) for the backend, and HTML/CSS/JavaScript on the frontend, and includes custom subdomain enumeration and reconnaissance tooling built to support the training exercises.

Tools

  • Burp Suite — manual request analysis and testing
  • Nmap — service and attack-surface discovery
  • Gobuster & FFUF — endpoint and content discovery
  • Node.js & Python (FastAPI) — platform backend
